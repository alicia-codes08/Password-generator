Password generator written in python. tkinter was used for the layout.

This password generator generates a password to use with eight figures. Those eigh figures are all random choosen elements from a elements-list.
The generated password is marked with "using password". Thats the password to use as an password. The password that was generated 
after "using password" is the password to keep. You write it somewhere down. Its the password that you used, but with 
elements, that are all moved after a fix choosen number. The only thing to keep in mind is the number, that are the 
elements from the keeping-password are away from the using-passwords elements.
